# DevFinder / GitHub User Search 🔍

A clean, responsive GitHub profile finder web application built as a beginner practice project to explore data fetching, client-side routing, and modern UI styling.

---

## ✨ Features

- **Instant Profile Search:** Search any public GitHub profile by username.
- **Detailed Profile Overview:** Displays name, bio, join date, location, website, Twitter/X handle, and organization.
- **Repository & Social Stats:** Quick metrics for public repositories, followers, and following count.
- **Graceful States:** Clear feedback for loading, user-not-found (404), and rate-limiting (403) states.
- **Responsive UI:** Tailored for mobile, tablet, and desktop screens with dark-mode styling.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Routing:** [TanStack Router](https://tanstack.com/router)
- **Data Fetching & Caching:** [TanStack Query](https://tanstack.com/query)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **API:** [GitHub REST API](https://docs.github.com/en/rest)
